AURA — EDITION 1.1
Single-page architecture / interior design portfolio

START HERE
Open documentation/index.html for the current owner guide.
Open index.html for the template. Keep scss and assets beside it.
Internet access is needed for Google Fonts and remote reference photographs.

INCLUDED
One HTML website with five main sections, four expandable project briefs,
dark/light appearances, mobile navigation and a local email-draft form.
Compiled CSS, optional Sass sources and vanilla JavaScript are supplied.
No build step is required for ordinary HTML/CSS edits.

STYLES
scss/main.css is the compiled stylesheet.
scss/enhancements.css MUST remain linked after main.css.
Optional Sass entry point: scss/main.scss.
Base tokens: scss/_variable.scss (singular filename).

CONTACT SETUP
Replace all studio@example.com occurrences in index.html: visible address,
mailto destination and form data-recipient. Remove the demo-address note.
The form only prepares a draft; visitors send it from their email service.
No backend, automated delivery, message storage or encryption is included.

CONTENT / ASSETS
The studio and project stories are illustrative. Photos are external mood
references, not bundled project assets. Replace them with authorized images
and factual descriptions before presenting a real practice.
The seller must define the license, resource notices and support policy.
This README does not grant blanket commercial rights to third-party assets.
