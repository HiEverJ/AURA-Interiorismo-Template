AURA 1.1 — SELLER NOTES

POSICIONAMIENTO
Portafolio editorial de una sola página para estudios de interiorismo y
arquitectura. El producto concentra la presentación del estudio en un recorrido
breve: introducción, filosofía, cuatro proyectos, servicios y contacto.
Su propuesta es la sencillez: dos apariencias y fichas desplegables, sin convertir
cada proyecto en una página adicional. No anunciarlo como multipágina.

TÍTULO SUGERIDO
AURA — Minimal Interior Design One-Page HTML Template

DESCRIPCIÓN SUGERIDA (EN INGLÉS)
AURA is a single-page HTML portfolio for interior design and architecture
studios. A restrained editorial layout brings together your studio story,
four expandable project briefs, service descriptions and an email-draft
inquiry flow. Includes dark and light appearances, mobile navigation,
compiled CSS, optional Sass sources, vanilla JavaScript and a dedicated
HTML owner guide. No build step is required for everyday customization.

CONTENIDO QUE SÍ INCLUYE
- 1 página HTML con 5 secciones principales.
- 4 proyectos de ejemplo con fichas desplegables nativas.
- 2 apariencias de color y preferencia local opcional.
- Navegación móvil y enlaces disponibles sin JavaScript.
- Formulario de borrador local con texto copiable y enlace a email.
- CSS compilado, fuentes Sass, JavaScript y documentación HTML.

LIMITACIONES PARA LA FICHA DE VENTA
No es WordPress, un CMS ni una plantilla de constructor visual.
No incluye hosting, reservas, backend, envío automático de formularios ni soporte
contratado. El comprador necesita conocimientos básicos de HTML/CSS.
Las imágenes son referencias externas; no se incluyen como archivos descargables.
Los proyectos son conceptos ilustrativos, no obras acreditadas del autor.
No afirmar compatibilidad comprobada, accesibilidad certificada ni puntuaciones
de rendimiento: esta revisión no incluyó pruebas.
